# 14. Glosario y bibliografía

[[13 - Resultados y conclusiones|← Anterior]] · [[Inicio|Índice]]

## 14.1 Glosario

| Término | Definición |
|---|---|
| **TPV** | Terminal Punto de Venta. |
| **Veri*factu** | Sistema de facturación verificable de la AEAT (huella + QR). |
| **Comanda** | Pedido asociado a una mesa. |
| **Arqueo** | Conteo de efectivo al cerrar el turno y diferencia con lo esperado. |
| **Factura rectificativa** | Factura que anula/corrige otra sin borrarla. |
| **Hash encadenado** | Huella SHA‑256 que incluye la huella de la factura previa. |
| **Security Rules** | Reglas de autorización de Firestore (servidor). |
| **Transacción** | Operación atómica: se ejecuta entera o no se ejecuta. |
| **MVVM** | Patrón Model‑View‑ViewModel. |
| **MOC** | *Map of Content*: nota índice que enlaza otras. |

## 14.2 Bibliografía y fuentes

- Documentación oficial de **Android** y **AndroidX** (developer.android.com).
- Documentación de **Firebase**: Authentication, Cloud Firestore, Security Rules,
  Emulator Suite (firebase.google.com/docs).

- **Material Design 3** (m3.material.io).
- **ZXing** (QR), **MPAndroidChart** (gráficas), **ML Kit** (escáner).
- Zakir Khan, *Cognitive Load* (github.com/zakirullin/cognitive-load) — guía de
  diseño aplicada a la calidad del código.
